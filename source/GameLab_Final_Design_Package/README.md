# GameLab Final Design Package

Ushbu arxiv Junior Academy GameLab bo‘limi uchun final UI referencelar, brandbook, agent implementation spec, game-card holatlari va 2D/3D assetlarni o‘z ichiga oladi.

## Qayerdan boshlash kerak?
1. `03_Brandbook/FINAL_GAME_LAB_DESIGN_SPEC.md` — yagona yakuniy dizayn va UX/UI manbasi.
2. `00_START_HERE/IMPLEMENTATION_CHECKLIST.md` — Codex/agent uchun bajarish tartibi.
3. `02_Device_Mockups/` — desktop/tablet/mobile referencelar.
4. `04_Game_Card/` — game card va uning state’lari.
5. `05_Assets/` — assetlar katalogi.

## Muhim
`06_Archive_Explorations/` ichidagi rasmlar oldingi iteratsiyalar uchun saqlangan. Ular final spec bilan zid bo‘lsa, FINAL spec ustun. `06_Archive_Explorations/` rasmlarini final UI sifatida ko‘chirmang.
