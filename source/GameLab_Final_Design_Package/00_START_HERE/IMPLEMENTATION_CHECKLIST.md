# Agent implementation checklist — GameLab

1. Mavjud Junior top navbar’ni qayta ishlat; chap sidebar qo‘shma.
2. Sahifa strukturasini FINAL_GAME_LAB_DESIGN_SPEC.md dagi tartibda qur.
3. Kurs yo‘nalishlarini Matematika, Ingliz tili, Dasturlash, Robototexnika, Raqamli ko‘nikmalar, Mantiq qilib sozla.
4. Global course chip filter barcha sahifa section’lariga ta’sir qilsin.
5. Catalog search/filter faqat catalog list’ni filter qilsin.
6. Header’da faqat Coin counter bo‘lsin; lightning counter bo‘lmasin. Coin tooltip qo‘sh.
7. Continue list faqat progressi bor, tugallanmagan o‘yinlardan tuzilsin.
8. Recommendations list faqat hali boshlanmagan o‘yinlardan tuzilsin; continue list bilan ID kesishmasin.
9. Har bir game card’da coin reward ko‘rsat.
10. Yangi / Davom etmoqda / Bajarilgan / Bloklangan card state’larini qur.
11. Search empty state, loading skeleton va network error state’larini qur.
12. Responsive: desktop ≥1280, tablet 768–1279, mobile ≤767.
13. Mobile chip label’larini qisqartirma; horizontal scrolling qo‘llagin.
14. Rang, typography, spacing, radius va copy uchun FINAL_GAME_LAB_DESIGN_SPEC.md ga amal qil.
15. Assetlardan `05_Assets/` ichidan foydalan; vaqtinchalik emoji bilan almashtirma.
16. Yakunda accessibility checklist bo‘yicha tekshir.

**Definition of done:** Desktop, tablet, mobile maketlar reference’ga mos; bo‘limlar takrorlanmaydi; kurs filterlari to‘g‘ri ishlaydi; har bir card reward ko‘rsatadi; empty/loading/locked/completed states mavjud.
